The disease and soil classifier models and their label/metadata files are included in this folder.

The 164 MB yield_model.joblib file is generated by notebooks/AgriSmart_Colab_Training.ipynb and is ignored by Git because it exceeds GitHub's 100 MB per-file limit. To enable yield prediction after cloning, generate AgriSmart_Models.zip in Google Colab, extract it, and copy yield_model.joblib into this folder.
